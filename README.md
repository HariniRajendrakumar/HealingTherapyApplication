# Healing Therapy Application

## How to run locally

1. Clone this repo:
   
         git clone https://github.com/HariniRajendrakumar/HealingTherapyApplication.git

2. Navigate into frontend and install dependencies:

        cd frontend
        npm install
        npm start

3. Navigate into backend and install dependencies:

        cd backend
        npm install
        npm run dev

4. Open your browser at:

Frontend: http://localhost:3000

Backend API: http://localhost:5001
